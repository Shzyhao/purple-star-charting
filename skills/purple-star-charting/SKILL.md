# Purple Star Charting（紫微斗数排盘）

## 何时使用

- 用户提供生日/时辰，想知道自己的紫微斗数命盘；
- 用户问紫微斗数的命宫、十二宫、四化、大限、流年、姻缘、合盘；
- 用户想了解传统术数体系的盘面如何阅读。

## 何时不用

- 用户问八字、六爻、西占等其他体系（本 skill 不覆盖）；
- 用户要求预测寿命、死亡时间或"命运判决"（拒绝并解释）；
- 用户要求医疗、投资、法律等专业建议（引导至专业人士）；
- 用户要求复制古籍原文（本 skill 只做转述与页码级引用）。

## 输入收集

开始排盘前确认 5 项，缺项先问，不要猜：

1. 性别（男/女）；
2. 公历或农历生日（优先公历，程序自动转农历）；
3. 出生时间（尽量到小时；不确定时说明可能在哪个时辰区间）；
4. 出生地（可选，用于提示真太阳时校正）；
5. 想问什么（本命/大限/流年/姻缘/合盘）。

## 执行步骤

1. 校验输入（时辰边界、闰月、晚子时）；
2. 在仓库根目录运行命令行（相对路径，不写死绝对路径）：

    python -m purple_star --gender 男 --solar 1990-05-15 --time 14:30 --year 2026 --out out

   农历输入：

    python -m purple_star --gender 女 --lunar-gz 辛未 --month 12 --day 13 --hour 酉 --year 2026 --out out

3. 读取 out 目录下的 md 报告与 svg 命盘图；
4. 按固定结构组织回答（见下）；
6. 需要指向古籍时，只给卷篇与页码，不复制原文。

## 输出结构

- 命盘要点（命宫、身宫、五行局、四化）
- 本命解读（性格、十二宫要点）
- 格局（初筛，说明非定论）
- 大限（当前十年）
- 流年（若用户指定年份）
- 一句话总结
- 免责声明

## 红线

- 不预测寿命、死亡、疾病结果；
- 不替代医疗、投资、法律、婚姻等专业建议；
- 不复制任何古籍原文，引用只到页码；
- 不编造引文、页码或命理结论；
- 不把术数结论说成事实或保证；
- 不区分"高人一等"的命格，不做歧视性判断；
- 生辰数据只在本地处理，不写入公开文件。

## 引用策略

只做转述与页码级引用，例如：传统排盘规则中，紫微定位按五行局与生日查表（参见原书卷二相关篇目，第 84 页附近）。

禁止：整句复制原文、拼接多句原文、以"原文是……"方式输出原文。

## 故障排除

- 缺少 lunardate：pip install -r requirements.txt；
- 生成 PNG 失败：缺 Pillow 或中文字体，改用默认 SVG；
- 中文显示方块：系统缺中日韩字体，安装 Noto Sans CJK 或改用 SVG；
- 排盘结果与别家不同：多为流派差异（四化、火铃、大限起宫），说明差异来源，不争对错。

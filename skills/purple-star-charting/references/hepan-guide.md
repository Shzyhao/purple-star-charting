# 合盘指南

## 输入

双方各自的性别、生日（公历/农历）、时辰；出生地可选（提示真太阳时）。

## 分析维度

1. 命宫对命宫：主星是否相同、五行局是否互补；
2. 夫妻宫互看：一方的夫妻宫主星是否与另一方命宫主星重合；
3. 四化互落：一方生年四化落在另一方盘的哪个宫，看"把什么带给对方"；
4. 大限节奏：双方当前大限在婚限还是事业限，是否错位；
5. 年龄差与角色：夫妻宫星曜的"年长/年少、主导/随和"倾向。

## 红线

- 不做"合不合/能不能结婚"的绝对判断；
- 不预测离婚、不替用户做婚配决定；
- 涉及感情冲突时，引导沟通与现实相处，不用命盘定罪；
- 不复制原文，引用只到页码。

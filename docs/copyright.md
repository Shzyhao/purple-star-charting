# 版权边界说明

## 1. 两层版权

- **古籍原著**：紫微斗数传统典籍的原著内容属公有领域，人人可用；
- **特定校注本**：现代出版社的校注、标点、编排、序跋等整理成果受版权保护。逐字转录某一校注本，等于复制该版本的整理成果，**不能公开**。

## 2. 本仓库的边界

本仓库**只包含**：

1. 排盘规则的代码实现（我们自己的代码）；
2. 规则性数据（星曜偏移、十干四化、纳音、大限小限规则等事实性规则）；
3. 项目自撰的白话解释（我们自己的文字）；
4. 由代码渲染的命盘图（我们自己生成）；
5. 到卷篇与页码级别的引用（如"参见卷二某篇，第 84 页"）。

本仓库**不包含**：

- 任何古籍扫描件或 PDF；
- 任何逐字整理稿、校勘稿或全文文本；
- 任何第三方电子书文本；
- 任何原文句子（引用只到页码，不复制文字）；
- 任何真实个人命盘数据。

## 3. 自动化检查

scripts/copyright_scan.py 会在本地与 CI 中扫描：

- 禁止的目录与文件（扫描件、校勘稿、第三方文本、chunks 等）；
- 中文引号引文（「」）；
- 原文特征句黑名单；
- 超大文本文件。

扫描不通过则不允许合并。

## 4. 如果你要引用古籍原文

请自行从公有领域的古籍版本（如明刻本、影印本）核对，并遵守所在司法辖区的合理使用规定。本仓库不提供原文，也不对使用者的引用行为负责。

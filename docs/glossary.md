# 术语表

| 术语 | 说明 |
|---|---|
| 命宫 | 十二宫之首，代表本人禀赋与一生大势 |
| 身宫 | 后天重心，与命宫同看 |
| 五行局 | 由命宫干支纳音决定的局数（水二、木三、金四、土五、火六） |
| 紫微 / 天府 | 十四主星的两系之首 |
| 十四主星 | 紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军 |
| 四化 | 化禄、化权、化科、化忌，由天干决定星曜性质 |
| 大限 | 十年一宫的大运，起运岁数等于五行局数 |
| 小限 | 一年一宫的小运，按生年支起宫，男顺女逆 |
| 流年 | 以当年太岁所在宫为流年命宫 |
| 斗君 | 流年正月的起点，用来起流月 |
| 三方四正 | 本宫 + 三合两宫 + 对宫，共四宫 |
| 飞星 | 宫干四化，飞入它宫，看宫与宫之间的影响 |
| 庙旺 | 传统星曜强弱等级（本工具不内置，见 limitations） |
| 强弱 | 本工具用五行生克法推算的星曜强弱 |
| 格局 | 主星与辅煞在命宫/三方形成的固定组合 |

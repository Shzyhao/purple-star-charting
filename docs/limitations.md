# 已知局限

1. **庙旺表未内置，强弱改用五行生克法**：传统庙旺表存在版本差异与整理版权问题，本项目不附带该表；强弱按星曜五行与宫位五行的生克关系推算（宫生星=得生、比和=旺、星克宫=耗、星生宫=泄、宫克星=受制），属项目自撰规则，可解释、可复现。用户可自备庙旺表，通过 --miaowang 加载（格式见 docs/data/miaowang-schema.md）。
2. **四化流派差异**：十干四化在不同流派/版本中略有不同，本项目采用一种通行方案，见 references/interpretation.md。
3. **火铃起法差异**：本工具按年支起火星、铃星（一种传统方案），另有按生时起法，结果会不同。
4. **大限起宫差异**：本工具采用"阳男阴女起父母宫、阴男阳女起兄弟宫"的规则，部分流派从命宫起。
5. **真太阳时**：程序按使用者给定的时间与时辰计算，未内置经度/均时差校正，请自行确认时辰边界。
6. **闰月与晚子时**：提供 --leap 与 --late-zi 选项，但传统各家处理不同，结果可能不同。
7. **流月/流日**：暂未提供；古籍对此的推法较简略，可靠性有限。
8. **解读为倾向性描述**：所有白话解释都是传统术数体系中的一种说法，不是事实判断。
9. **回测**：内部曾以文献命例做规则核对，存在少量差异（多因版本误刻），说明实现并非绝对精确。

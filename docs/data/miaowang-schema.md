# 自备庙旺表格式

本工具不内置任何版本的庙旺表（不同版本、不同整理者的表存在差异，且整理成果可能受版权保护）。
如果你有自己的表，可以按下面格式准备 JSON，通过

    python -m purple_star ... --miaowang my_miaowang.json

加载，报告会在十二宫概览里附上对应星曜的庙旺等级。

## 格式

    {
      "星曜名": {
        "宫位地支": "等级"
      }
    }

- 星曜名：紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军等；
- 宫位地支：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥；
- 等级：廟、旺、得地、利盆、平和、不得地、陷（也兼容简体写法：庙、得地、利盆/利盆、平和、不得地、陷）。

## 示例（仅示意结构，不含真实数据）

    {
      "示例星": {
        "子": "旺",
        "丑": "得地",
        "寅": "陷"
      }
    }

## 说明

- 文件里的等级只影响报告展示，不参与排盘；
- 若等级缺失，该星曜不显示庙旺；
- 请自行确认所用表格的来源与版权，仓库不附带任何版本的庙旺表。

# 设计说明

## 1. 分层

- consts.py：规则常量（干支、五虎遁、纳音、四化、星曜偏移、辅星规则）；
- chart.py：排盘核心（纯函数，输出 JSON 可序列化结果）；
- interpret.py：白话解读（自撰文本 + 规则化生成）；
- render.py：命盘图（SVG 为主，PNG 可选）；
- strength.py：星曜强弱（五行生克法）与可选庙旺表加载；
- cli.py：命令行入口。

## 2. 设计原则

1. **规则与文本分离**：排盘只依赖规则数据，不依赖任何古籍文本；
2. **可复现**：同一输入必得同一输出，便于测试与核对；
3. **自撰解读**：解读文字全部由项目撰写，不复制原文；
4. **页码级引用**：需要指向原书时只给卷篇与页码，不给原文；
5. **离线优先**：不联网、不上传数据。

## 3. 排盘规则说明

- 命宫、身宫：以寅起正月、逆数生时安命、顺数安身；
- 五行局：五虎遁定命宫天干，纳音定局；
- 紫微定位：按局数与生日查规则表；
- 十四主星：紫微系逆行、天府系顺行；
- 辅星：昌曲按时、辅弼按月、魁钺禄存按年干、马按年支等；
- 四化：按生年干（大限、流年各自起）；
- 大限：阳男阴女顺行、阴男阳女逆行，起运岁数等于局数；
- 小限：按生年支起宫，男顺女逆。

## 4. 扩展点

- 新增格局：在 interpret.detect_geju 中增加规则；
- 新增专题（婚姻/事业/财运）：新增模块，输出仍走 analyze 的固定结构；
- 合盘：新增 hepan 模块，输入两份 chart 结果。
